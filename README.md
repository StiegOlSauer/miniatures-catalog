# Miniatures Catalog

A read-only, single-page catalog of a TTRPG miniature collection: browse by photo, filter by
origin, kind, tags, size or storage location, and build a "shopping list" of models to pull for
your next session. Built to be hosted for free on GitHub Pages.

- **Spec:** [SPEC.md](SPEC.md) — the full design and implementation spec.

The spreadsheet is the source of truth; nothing on the site itself is editable. To update the
catalog, edit the spreadsheet, run `tools/build.py`, and push.
